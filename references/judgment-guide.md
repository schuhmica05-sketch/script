# 判断说明

**结构负责稳定，内容负责惊喜。** 下列结构只规定论证方向，不是逐句模板或段落配额。先看真实材料，再选择结构；结构选定后允许语言、节奏、故事、细节、情绪、比喻和表达顺序自由变化，只要不跑题、不编造、不反复解释。

## 七种母结构

### S1｜诊断纠偏型

用户已经知道有问题，但对原因的解释不够。用“具体处境 → 常见解释/做法 → 为什么不够 → 真正原因 → 机制 → 新判断”推进。原因要有依据；材料只支持一种可能时，保留条件，不把假设说成诊断结论。

### S2｜对比决策型

用户在两种方案、认知或做法间选择。用“A → B → 表面差异 → 真正差异 → 判断标准 → 适用边界”推进。比较可以围绕用户自己的两种做法，不必虚构同行表现或竞争产品数据。

### S3｜案例复盘型

已有真实成功、失败、损失、代价或转折。用“异常/强结果 → 背景 → 做了什么 → 发生什么 → 为什么 → 可迁移判断”推进。每段故事承担论证任务；事实没有证明因果，就把原因写成有边界的判断。没有案例不用此结构硬填。

### S4｜过程证据型

最大障碍是“不相信你真的会/做到了”，也可用真实动作让观众看见自己将得到的具体照顾。表达动作中的判断、取舍及对观众的价值；有来源的难点与差异值得讲，但不必把每个动作写得复杂。只排列第一步、第二步不能证明专业；也不能把可以设想的动作说成项目已做。

弱：建档 → 看档案 → 沟通 → 跟踪。

强方向：顾客上次说过的话如何在这次服务接上，有哪些准备已经有人替她做了？旧记录如何帮助继续询问，可作为一个自然动作，不要让观众听整篇档案规则。表达必须有当前项目材料支持，不能凭校准例子补造服务机制。

### S5｜价值拆解型

知道商品、项目、价格，却不知真正买到什么。用“表面商品/价格 → 实际体验/结果 → 具体动作 → 为什么构成价值 → 谁会在意”推进。明确区分产品目标和已有结果，不把培训周期写成学成保证，不根据价格推断客户一定嫌贵。

### S6｜体验验证型

用户需要亲自试，判断适不适合、喜不喜欢、该不该选。给一个可实施的低成本测试，让其完成后观察自己的行为/反应，再得到判断。可把尚未执行的任务写成邀请，不能预写结果；一次体验也不能证明长期效果。

证据状态为 **P2**：逻辑与人类专家反馈支持较强，现有真实案例样本相对少。它不是跨行业已验证的最优结构。例如“拍摄、剪辑、编导先试哪个”可能明显适用，但仍应依据当次条件。试听可以帮助形成判断，不等于必须在现场动手或课程已提供实操体验。

### S7｜风险分层 / 事件拆解型

适用于法律、合规、税务、用工、加盟和经营风险中需要定位自身处境的内容。用“异常事件/风险 → 为什么发生 → 风险机制 → 按身份/行为/程度分层 → 不同层级意味着什么 → 下一步先确认什么”推进。

分层用于找出事实差异，不是自行判罚。岗位名称不能替代实际行为；风险机制的假设不能当作确定因果。事实不足时说明谁做了什么、知悉什么、何时发生、材料是什么等关键缺口；涉及具体法律结论还需适用地区、时间和现行依据。模拟例子要明确为模拟且非法律结论，不制造“全部人都会出事”的恐惧。

## 三稿策略

先问有没有明显优解，不能为多样性强选三种。明显优解：同结构三稿。无唯一明显优解：从有材料支持的结构里选三种各写一稿，不选缺少支撑的较弱路线凑数。去掉开头、金句和结尾，主体须在观察视角、材料组织、解释重点、任务体验或论证路径上有可辨差异；结构标签、开头或同义替换不是证据。差异只能由同一组真实材料的组织和判断产生，不能靠新编顾客故事、疗效或同行缺点。

## 写完后的四个提醒

这些不是正文必填模块，只在完成初稿后帮助修正。

1. **开头有没有必要继续听**：优先让用户先看到自己的利益、风险、欲望、冲突或具体处境，但不强制反认知、数字钩子或固定句式。
2. **有没有具体东西**：能用真实动作、经历、原话、对比或结果说明，就少用抽象词。专业不等于复杂；没有真实难点，不人为制造难点。
3. **有没有反复解释**：同一个意思再次出现时，必须增加新事实、判断、情绪、对比或行动价值；只是换词重说就删掉。
4. **有没有自然的商业关联**：观众看完应更愿意了解这个人/业务，但不要求显式写“为什么选我”。判断锚点有自然好句就保留，没有就不造；事实与安全边界主要在后台执行，只有影响理解、选择或安全的必要条件才进入正文。

CTA 与商业关联分开检查：自然结束也可以有购买理由；一个咨询入口本身不构成购买理由。L0 的示例只能证明无 CTA 分支有示范，不能据此声称 L1—L3 已经过行为验证。

## CTA 可选层

| 层级 | 使用条件 | 表达方向 |
| --- | --- | --- |
| L0 无 CTA | 认知已经完整，行动会突兀 | 自然结束 |
| L1 互动 | 有价值的轻问题 | 询问观众卡在什么具体环节 |
| L2 资料动作 | 资料确实存在且交付方式已确认 | 用真实名称和入口，不编清单、名额 |
| L3 结构化咨询 | 有真实承接，需提高咨询信息质量 | 收集行业、产品、当前困难等必要信息 |

互动不是承诺诊断或无条件提供服务。结尾删掉 CTA 反而自然，就选 L0；筛选客户是结果，不单独发展成第八种结构。
